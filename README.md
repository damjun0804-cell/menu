# ˚₊‧꒰ა 미르의 메뉴판 ໒꒱ ‧₊˚

방송 중 사용할 수 있는 **메뉴판 정보**와 시청자분들이 적립해둔 **킵(Keep) 리액션 수량**을 실시간으로 확인할 수 있는 페이지입니다.

---

## 🥄 주요 기능 안내

1. **메뉴판 확인**
   - 방송에서 요청할 수 있는 기본 메뉴와 필요한 개수를 확인할 수 있습니다.

2. **✨ 킵해둔 리액션 목록 (실시간)**
   - 시청자분들이 적립해둔 리액션의 남은 수량이 실시간으로 표시됩니다.
   - 적립 및 사용 내역이 발생하면 별도의 새로고침 없이 즉시 업데이트됩니다.

3. **➕ 킵 추가 / 사용 등록**
   - 새로운 리액션을 적립하거나 사용했을 때 내역을 직접 기록할 수 있습니다.
   - 아이템 선택, 수량, 닉네임을 입력하여 등록합니다.

4. **📜 히스토리 보기**
   - 지금까지 적립되거나 사용된 모든 상세 기록을 날짜별로 확인할 수 있습니다.

---

## 💡 사용 방법

### 1. 킵 리액션 적립 및 사용 기록하기
1. 상단의 **`➕ 킵 추가 / 사용 등록`** 버튼을 클릭합니다.
2. 구분에서 **[적립]** 또는 **[사용]**을 선택합니다.
3. 목록에서 해당 **아이템**을 선택합니다.
4. **수량**과 **닉네임**을 입력한 뒤 **`기록 등록`** 버튼을 누릅니다.

### 2. 기록 내역 확인하기
- 상단의 **`📜 히스토리 보기`** 버튼을 누르면 누적된 적립/사용 기록을 모달 창으로 확인할 수 있습니다.
